## Problem

Same gap as `ut-plugin-language-de`'s copy of this script (ut-docs#312: no
shared implementation between core and the packs, kept in sync by hand).
`scripts/check-key-drift.sh`'s `load_json()` parsed both core's en.json and
this pack's es.json with plain `json.load`, which silently keeps only the
LAST of a duplicated top-level key. Verified directly against `main` while
starting this card: `locales/es.json` had 7 real duplicate keys live right
now — the same `orders.view.*`/`pos.toast.receipt_*`/
`elevation.summary.*` set as the German pack's own incident (see that
repo's `docs/code-reviews/2026-09-09-duplicate-locale-key-guard-1872.md`
for the full history), independently confirmed here.

## What shipped

- `scripts/check-key-drift.sh`'s `load_json(path, label)`: now reads the
  raw key/value pair list via `object_pairs_hook`, and fails (naming the
  file and every duplicated key) before returning, for BOTH the core en.json
  load and the es.json load — same hard-failure class as invalid JSON.
- `scripts/check-key-drift.test.sh`: two new cases (search "ut-docs#1872")
  — a duplicate key in es.json, and a duplicate key in the fetched core
  en.json.
- `locales/es.json`: the 7 live duplicates removed. Five were byte-identical
  copies (trivial dedup); two were resolved by merit —
  `orders.view.refund_link` kept "Devolver en su lugar" (verb form) over
  "Devolución en su lugar" (noun form), and `elevation.summary.backup_restore`
  kept the copy using "copia de seguridad"/"carpeta de copias de seguridad"
  over one that dropped "de seguridad", to match this file's own
  established terminology (sibling key `elevation.summary.backup_now` also
  says "copia de seguridad").
- `manifest.json`: version 1.1.25 -> 1.1.26 — same "a locale-only fix needs
  a version bump to actually ship" precedent as the German pack's PR #207 /
  this pack's own PR #208.

## Independent review (fresh-context Sonnet subagent)

**Verdict: PASS**, no blockers. Verified live: `scripts/validate.sh`,
`scripts/check-key-drift.test.sh` (all 26 cases including the 2 new ones),
