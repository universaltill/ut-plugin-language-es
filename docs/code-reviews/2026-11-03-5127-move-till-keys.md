## Hand check of meaning (all 68 keys)

Behaviour per `claim.md` / `move_approval.go`: manager or admin approves
or declines with a PIN; three wrong PINs decline; the till keeps selling;
nothing is wiped; sales history is merged into the other account. Every
Spanish string carries that meaning: `trasladar`/`traslado` (never
`eliminar`/`borrar`/`transferir datos`), "No ha cambiado nada" present on
every refusal/result key where English has "Nothing changed", the warning
states the consequence and "Soporte nunca le pedirá que haga esto".

Register and terminology: usted throughout (Apruébelo, Conéctese, Pida,
Póngase en contacto, Inténtelo); `caja` for till, `tienda` for shop,
`responsable` for manager (the pack's term, 36 uses; `gerente` only 3),
`administrador`, `propietario` for owner, `vincular` for pair (matches the
existing `settings.enrol.*` neighbours), `nube` for cloud, `soporte`.
Grammar agreement checked: "Trasladada a %s" (la caja), "Rechazado." (el
traslado). `%s` in `notice_pending` is a shop name (`en.meta.json`), so
"%s ha solicitado trasladar esta caja a su tienda" is right.

Author's claimed fix verified: `settings.staff_links.help` is usted —
"Añada personal, asigne sus PIN y elija qué puede hacer cada rol."
